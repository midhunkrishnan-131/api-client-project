🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

1. Install dependencies:
   $ pip install -r requirements.txt

2. Copy environment template:
   $ cp .env.example .env
   $ edit .env  # Add your API key

3. Test retry logic:
   $ python test_retry_backoff.py
   
   Watch for logs showing exponential backoff:
   - Attempt 1: 0.42s wait
   - Attempt 2: 2.15s wait
   - Attempt 3: 5.87s wait
   - Attempt 4: 14.23s wait
   - Attempt 5: 31.45s wait

4. Test pagination:
   $ python test_pagination.py
   
   Fetches real data from JSONPlaceholder

5. Use in your code:
   from api_client import APIClient
   
   client = APIClient(
       base_url='https://api.example.com',
       api_key_env_var='API_KEY'
   )
   
   # Single request
   response = client.get('users', params={'page': 1})
   
   # Paginate through results
   for user in client.paginate('users'):
       print(user['name'])


💡 KEY FEATURES
═══════════════════════════════════════════════════════════════════════════

✓ Smart Retry Logic
  - Retries ONLY on 429 (rate limit) and 5xx (server errors)
  - Fails FAST on 4xx client errors (no retry waste)
  - Max 5 attempts, respects Retry-After header

✓ Exponential Backoff + Jitter
  - Formula: min(60, 2^N - 1 + random jitter)
  - Prevents "thundering herd" (all clients retrying at once)
  - Capped at 60 seconds

✓ Pagination Generator
  - Memory efficient (yields 1 item at a time)
  - No hardcoded page count
  - Stops automatically when API returns empty page

✓ Session Reuse
  - Default headers set once (Auth + Content-Type)
  - Connection pooling across all requests
  - Clean API key handling from .env

✓ Loud Failures
  - Missing .env keys crash at startup (not silently later)
  - Structured logging shows retry decisions

🎯 DESIGN PHILOSOPHY
═══════════════════════════════════════════════════════════════════════════

Fail Loud, Not Silent
  Missing config crashes immediately at init, not silently later

Retry Only What Recovers
  4xx = permanent (bad data, no auth, not found)
  5xx = transient (server down, temporarily busy)

Respect Server Signals
  Honor Retry-After header when provided

Memory Efficient
  Pagination uses generator, not loading all pages at once

Observable
  Structured logging at every retry decision

Reusable Session
  One place for auth headers; connection pooling
